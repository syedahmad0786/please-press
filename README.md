# THE BUTTON.

A single beautiful button on a clean page. First clicks are cute. Then particles, sound, fake system messages, lore, and a small ceremony.

Live: will be filled after deploy. Repo: https://github.com/syedahmad0786/please-press

## Run locally

```bash
npm install
npm run dev
```

## Acts

Press counts unlock acts at 1, 10, 50, 100, 250, 500, 1000, 2500, 5000, and 10000. Your count is stored in `localStorage`. A global counter is best-effort (`/api/click`).

## Fork it

Change `src/acts.ts` to write your own museum. MIT.
